# 从这里开始：统一运行菜单

这是本工程**唯一的日常操作主指南**。连续窗口细节见 [连续分支指南](BRANCH_continuous-tracking_傻瓜式操作指南.md)，原离散真机流程细节见 [操作文档](操作文档.md)。两种策略共用本菜单，但停止语义不同。统一入口不表示真机验证通过。

## 1. 进入工程，使用已有环境

环境准备完成后，每天只需：

```bash
cd /home/user-linux/robotics_cs/ur7e_px6d_contour
source /home/user-linux/robotics_cs/.venv312/bin/activate
python run_project.py
```

环境路径若不同，激活你已经准备好的对应环境。菜单使用当前 `sys.executable`，所有子程序的工作目录固定为本工程；清除子进程 `PYTHONPATH` 并禁用 pytest 自动加载外部插件，避免 ROS 环境干扰。菜单不安装或升级依赖，不创建环境、不替换系统 Python。缺依赖时会报告，先核对已有环境再按项目 requirements 处理。

日常流程：**进入工程并使用已有环境 → `python run_project.py` → 选择菜单编号 → 按提示操作 → 查看实际结果目录**。不需要记住其他脚本命令。

路径提示可输入完整路径（含空格时无需引号）；相对路径以工程目录为基准。输入 `:q` 取消；无效路径或时长可重新输入。场景文件按原加载器校验，带 `base_config` 的场景仍按该文件所在目录解析引用。子程序失败后保留错误，操作者按回车才回菜单，不自动重试或启动下一任务。

## 3. 最短连续策略预演

1. 打开菜单，输入 **15**。
2. 场景提示按回车使用 `simulation/scene_continuous.yaml`，也可输入已有场景路径。
3. 窗口标题为 `SIMULATION / SYNTHETIC FORCE`；点 `Start`。初始 READY 不会自行开始。
4. 可用 Settings 选择形状、拖动目标、修改仿真摩擦；详细按钮与限制见连续分支指南。
5. 默认手动停止，无总运行时限；Stop、Q、Esc、终端 Ctrl+C 或关闭窗口结束。保护仍有效，停止不等于整圈完成。
6. 记录终端打印的实际 `run_dir`。结束后可在窗口 Save PNG；只以实际输出提示为准。回菜单 **19** 选择该目录，查看停止信息并生成静态图。

无窗口时用 **16**，选择场景并输入有限正数秒数（回车 12）；菜单始终传 `--duration`。它只缩短原预算，可能因保护更早停止。自动测试必须有限终止。**15 不传 duration；18 不覆盖真机预算，真机仍要求原有限预算及配置/现场检查。**

## 4. 共用设备、TCP 与标定

先确认现场安全，再用 3 检查 PX6D、4 检查机器人状态、9 读取 TCP。菜单 9 读取的是示教器当前 **active TCP offset**，不是探针针尖标定算法；菜单会打印旧值和读取值，并自动写入 `config.yaml` 的 `tcp.offset`，同时打印原配置备份路径；完全一致时不改写、不重复备份。只改六个偏移值，保留其他字段与注释，不调用 `setTcp()`。读取/校验失败时不写入，配置在读取期间被改动时拒绝覆盖。

换探针按此顺序：

1. 在示教器完成针尖 TCP 标定并启用正确 TCP，核对工具安装、姿态、payload/CoG。
2. 确认示教器已启用正确 TCP 后，菜单 **9** 读取并自动保存到本地 `config.yaml → tcp.offset`，核对终端打印的值与备份路径。
3. 重新采集相关标定：**7** 保存扫描 P0/P1，**13** 保存箱体四角，需要独立复位点时用 **10** 重新保存。
4. **8** 检查扫描方向与 TCP 绑定；**14** 检查四角几何；**17** 检查连续入口实际读取的扫描/箱体标定及配置。
5. 现场核对路径、设备、受力方向和所有安全条件，才进行所选策略的真机验证。

菜单读取 TCP 不能代替示教器针尖标定，也不能证明本地旧标定仍有效。不要复制错误 TCP 来消除报错。

扫描标定 7：用示教器到 P0 并静止，输入 `SAVE_P0`；沿初始搜索 XY 方向到 P1 并静止，输入 `SAVE_DIRECTION`。P1 仅定义初始方向；保存沿用原工具的检查与规则。8 打印并生成扫描标定预览图，属于原工具原有行为。

菜单 7 在每次 `SAVE_P0` / `SAVE_DIRECTION` 后独立建立 TCP 读取会话，采样后断开，不跨示教移动复用旧控制接口。SDK 按原默认方式加载辅助脚本；只读取 TCP/位姿，不发送运动或 setTcp，不调用自动 reupload/解锁恢复。输入保存指令前须结束示教移动并保持静止，确认 Remote Control 可用。P1 读取失败时不保存该点，等待明确重新输入 `SAVE_DIRECTION`；输入 `CANCEL` 结束并保留未完成 P0。旧进程已退出的情况需要重新选择 7，重新采集 P0/P1，不能直接把终端打印值补成有效标定。

箱体四角 13：沿箱体周边依次示教 workspace P0/P1/P2/P3，各点静止后按回车读取；`ABORT` 取消；核对拟合后 `SAVE` 保存，已存在文件由原工具备份。这里的四角标签不是扫描 P0/P1。原工具元数据可能仍为 `active_tcp_verified: false`，不能当作已在线核验。14 只复用已有校验器打印原始四角、派生矩形和误差，不修改文件；20 用已有工具生成日志的箱体坐标图，不是新增三维碰撞检查。

17 复用连续入口 `--check-calibration`，离线读取现有文件并检查配置/SDK 契约，不构造硬件设备；离线缺 SDK 或校验拒绝应如实处理，不能跳过或伪造 `site_verification`。菜单 9 按明确选择更新本地 TCP；扫描/箱体/复位标定及现场记录仍不会随之自动修改。

## 5. 真机运动：先选择策略，再确认

| 菜单 | 菜单确认词 | 子程序原确认与停止行为 |
|---|---|---|
| 11 独立返回 | `OPEN_REAL_RESET` | 原工具显示路径后要求 `RETURN_TO_RESET`；无独立复位文件时使用扫描 P0，要求 `RETURN_TO_P0` |
| 12 原离散扫描 | `OPEN_REAL_SCAN` | 可能在等待 `START` 前先返回 P0；Q 按原配置正常停止并返回扫描 P0，Esc/Ctrl+C 或异常不自动返回 |
| 18 连续扫描 | `OPEN_CONTINUOUS_SCAN` | 保留原 `START`；离 P0 时 START 后启动返回、到位后进入扫描；Q/Esc/Ctrl+C 均原地停止，不自动返回 |

任何菜单确认词都不代替子程序确认。输入错误、空输入或 `:q` 不启动真机子程序。菜单不自动输入 START、不自动解锁保护、不恢复运动、不重试。第 12 项始终是原离散策略，连续扫描请选择 **18**。

连续 18 的当前扫描顺序：`python run_project.py` → **18** → 按现有提示确认 / baseline → `TARGET_SEARCH` 沿已保存的 P0→P1 方向，以 **18 mm/s 名义速度**搜索（保留原加速度渐进上升）→ 接触阈值触发 `FIRST_CONTACT`，立即零运动并请求停止 → 实测 XYZ 速度连续 ≤0.1 mm/s 达 80 ms，且接触/方向满足原确认条件 → 低速 `CONTINUOUS_TRACKING`。确认当帧仍停止；未停稳或确认超时不允许开始贴边。18 mm/s **仅属于初始搜索**；贴边切向仍 1 mm/s，法向上限仍 0.5 mm/s。

本次速度修改复用现有 TCP、P0/P1、箱体四角和 reset_pose，不要求重新标定。搜索与贴边分别使用速度保护，搜索执行边界额外预留计算出的停车余量；力/力矩、数据新鲜度、30 ms 周期限制和 watchdog 等仍有效。完整数值与离线证据见 [连续技术说明](CONTINUOUS_TRACKING.md)。

确认前逐段检查当前点到 P0/复位点的返回路径，以及后续搜索/扫描空间；三段返回没有机器人本体、箱体、夹具、线缆的碰撞规划。以实际配置和现场核验为准，不采用历史文档中的数值作为授权。异常后先现场排查，再决定是否用 11 独立返回。

独立返回及原离散返回在每段停止后，会继续采集力和 TCP 状态，等待实测线速度满足控制器原停稳判据，再复查位置/姿态。等待计入原单段超时，不清除停止保护或自动重发运动。如果下一段前的新观测又不满足停稳条件，仍会拒绝运动。打印某段 target 只表示准备该目标，不表示运动命令已发送。

子进程直接使用当前终端，保留 START 输入回显、Q/Esc 及 Ctrl+C；菜单等待它结束和安全收尾后才接受下一任务。退出码 0 也可能是用户取消或正常停止，不表示扫描、几何或真机验收通过。

## 6. 选择实际结果目录

19 列出 `data` 和 `simulation_outputs` 下有日志标记的目录及**完整路径**，也可粘贴子程序打印的实际目录。没有默认“最新真机”；时间或目录名不是硬件模式证据。

连续日志依据快照中的连续入口标记识别策略，设备模式读取 summary 的 mode；旧离散样本依据记录格式识别策略，无法证实真机/仿真时显示“未知”。损坏元数据、未知格式、缺文件、空采样会明确报错，不虚构产物。

- 连续日志：已有 `tools/visualize_continuous_run.py`，显式 `--format none`，默认只生成 PNG，不批量编码视频；重复图采用工具的新文件名。
- 原离散 samples 日志：已有 `tools/visualize_run.py`，生成诊断图；会重新生成其同名派生 PNG，不改采样 CSV 或配置快照。
- 原离散 simulation_log 日志：已有箱体坐标可视化，菜单会要求匹配本轮的四角标定，不制造仿真箱体标定。
- 20：显式选择运行目录及匹配的箱体标定，优先提示本轮标定快照；在新的 `workspace_view_时间戳` 子目录输出，未传 `--overwrite`。

工具只展示已有观测。缺独立目标真值或力分量时应保持未知，不用回放证明闭环成功。是否保存成功、产物文件名及位置均以子程序实际打印和实际文件为准。

连续扫描若报 `continuous measured speed exceeds experimental limit`，表示对应阶段的实测 XYZ 线速度保护终止了实验，Z 分量也参与检查。搜索名义上限 18 mm/s、贴边独立上限约 1.118 mm/s；各自 1.2 倍为短时确认门限，超过 1.5 倍立即停止。轻微超限最多 20 ms 或 3 个不同时间戳包，重复包不增加计数或清除记录，过期数据仍拒绝。新运行的错误信息会打印 `measured_xyz`、`trip_limit` 和 `actual_vxyz`（单位 m/s），`termination.json` 的 `speed_limit_observation` 保存触发该保护的读取值、位姿和门限。它与普通 `tcp_speed`（最后一次有效观测）、`scan_stop_snapshot.json`（停止后观测）含义不同，不能互相代替。旧运行没有此字段时，不能从最后一条 CSV 或停止后的零速倒推出触发速度；先保留实际运行目录、核查故障，不通过放宽门限或自动重试继续运动。
