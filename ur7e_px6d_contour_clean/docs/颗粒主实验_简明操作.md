# 颗粒主实验简明操作

启动命令（前台交互终端）：

```bash
cd /home/user-linux/robotics_cs/ur7e_px6d_contour_clean
/home/user-linux/robotics_cs/.venv312/bin/python run_continuous_tracking.py --execute
```
也可运行 `run_project.py`，选择 **18**，按提示 Enter 启动。

实验准备：

- 核对 `config.yaml` 的机器人、PX6D、传感器安装变换和 active TCP；TCP 须与标定一致。
- 核对 `scan_calibration.yaml` 的 P0、扫描深度和初始搜索方向。
- 核对 `workspace/config/workspace_calibration.yaml` 及完整运动路径；基座水平；抬升位置须脱离颗粒及目标。
- P0 扫描深度须只有颗粒背景、未接触目标。

操作步骤：

1. 核对启动路径，按提示 Enter：抬升、调正探针、移动到 P0 正上方。
2. 在抬升位置确认静止空载，按 Enter 采集空气零偏。
3. 输入贴边速度倍率（如 `1`、`2`、`3`，Enter 默认 1 倍）；核对显示的本次速度。
4. 按下降提示 Enter：下降到 P0 扫描深度并停稳。
5. 确认只有颗粒背景且静止，按 Enter 采集颗粒背景力，随后自动开始搜索。
每个提示出现后单独按 Enter，不要预先连按；倍率仅调整本次贴边名义切向速度。

正常流程：SEARCH → FIRST_CONTACT（首次停车确认）→ TRACKING → RECOVERY（丢边后圆周搜索）。
RECOVERY 按 2／4／6 mm 半径逐圈搜索；接触即恢复 TRACKING，再次丢边从 2 mm 开始，三圈无接触则停止。

停止：运行中按 **Q** 原地停止，不自动返回；紧急情况使用示教器硬件急停。
结果：等待停稳和保存完成；终端显示本轮目录，默认 `data/real/continuous/run_*/`。
目录内：`samples.csv` 实验数据；`termination.json`、`termination.txt` 停止原因；`实验回放.html` 浏览器回放。
