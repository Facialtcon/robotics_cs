# 固定目标连续跟踪实验操作指南

本实验用于固定正方体、无颗粒介质的连续轮廓跟踪。首次接触后继续跟踪，丢边时使用原圆弧恢复；所有共有控制与硬件参数来自 `config.yaml`。

## 1. 唯一日常启动命令

在 `robotics_cs` 仓库根目录执行：

```bash
.venv312/bin/python ur7e_px6d_contour_clean/run_fixed_target_tracking.py
```

无参数启动只显示中文菜单，不自动模拟、不连接机器人。使用前台交互终端，根据每次提示操作。

```text
========== 固定目标连续跟踪实验 ==========
1. 开始真机实验
2. 标定 P_ref
3. 新增 / 修改 / 删除 P0
4. 查看已有标定
5. 标定正方体四角点
6. 检查标定与工作区域
7. 离线模拟
0. 退出
请选择：
```

每项操作完成后返回主菜单。在起点选择或 P0 子菜单输入 `0` 返回；采集和运动确认时按 `Q`、`Esc` 或 `Ctrl+C` 取消，按原流程完成必要的停车与保存后返回菜单。主菜单按 `0` 退出。

## 2. 菜单功能

| 菜单 | 操作说明 |
|---|---|
| 1. 开始真机实验 | 选择已有 P0 序号或名称，再进入原连续跟踪运行流程 |
| 2. 标定 P_ref | 人工示教参考点并停稳，按原单点标定提示读取和保存；重标已有参考点时可选择保留 P0 XY 或清空 P0 |
| 3. 新增 / 修改 / 删除 P0 | 先选择子操作；新增时输入名称，修改或删除时选择已有 P0；删除需原确认操作 |
| 4. 查看已有标定 | 显示 P_ref、P0 XY 和方向等标定信息，不连接设备 |
| 5. 标定正方体四角点 | 按周界顺序人工示教 P1→P2→P3→P4，逐点停稳、按 Enter 读取 Base XY，只保存显示轮廓 |
| 6. 检查标定与工作区域 | 离线检查全部已有 P0/P_ref、TCP 身份、工作区域及搜索几何，不连接设备 |
| 7. 离线模拟 | 运行原模拟器的合成正方形场景，不连接硬件；结束或停止后返回主菜单 |

P_ref/P0 标定直接使用现有单点实验的采集与保存功能。四角点标定使用已有只读采集功能。选择标定操作会连接机器人读取数据，人工移动由示教器完成，标定操作不发送自动运动指令。

已有有效标定时可直接使用。涉及已有 P_ref 的重标定，按提示确认是否保留 P0；取消时原文件保持不变。

## 3. 起点、工作区域与目标轮廓

| 文件 | 用途 |
|---|---|
| `config.yaml` | 原主工程共有参数 |
| `single_point_calibration.yaml` | P_ref 和多组 P0 |
| `workspace/config/workspace_calibration.yaml` | 原标定工作区域四角点，负责运动边界 |
| `target_geometry_calibration.yaml` | 正方体四角点，仅负责回放显示 |

实验起点使用 **P0.xy 和 P_ref.z**；初始搜索方向由 P0→P_ref 的 XY 方向确定。P_ref 是方向和统一高度的参考，**不是运动终点**。探针通过原自动调正流程朝 Base −Z。

工作区域直接复用主工程保存的原始四角点，保留真实四边形检查、边界 margin 和制动余量。`workspace.enabled=false`、`real_test_xy_limits=null` 时仍使用该区域，不需要独立 XYZ 配置或额外现场确认标记。

固定目标、起点及所需运动空间应处于原标定区域内，原区域应适用于当前工具和夹具。超出原区域时按原保护拒绝或停车，不修改、放大或缩小原标定坐标来绕过边界。

正方体四角点只取 Base XY，忽略 Z 和姿态，不参与搜索、力反馈、接触判断、丢边恢复或停止。没有目标轮廓标定也能运行和回放。

## 4. 真机实验基本步骤

1. 按原主工程要求准备机器人和 PX6D；自动运动时使用 Remote 模式。目标、夹具固定，起点无接触，抬升及调正空间可用。
2. 在主菜单选择 `4` 查看起点，选择 `6` 检查标定与工作区域；处理具体报错后再开始实验。
3. 选择 `1`，输入已有 P0 序号或名称，例如 `A`。
4. 查看终端打印的生效配置、方向和启动路径，按原 Enter 提示授权准备运动。机器人抬升、自动调正探针并定位到 P0 上方。
5. 在抬升位置确认探针处于空气中、无接触且静止，按提示采集空气零偏；不采集颗粒背景力。
6. 输入贴边速度倍率；直接回车使用 `1` 倍。终端会显示本次名义速度，仍受原速度、加速度和力反馈保护约束。
7. 按原下降/搜索提示按 Enter，下降到 P_ref.z 并停稳，然后沿保存方向直线搜索。
8. 首次接触后由原策略请求制动、确认实际停稳和有效接触，再进入连续轮廓跟踪。
9. 实验结束后原地制动、确认实际停稳、保存日志并生成 HTML，返回主菜单。

运行时按 `Q`、`Esc` 或 `Ctrl+C` 请求停止，等待制动、停稳和保存完成；迫切危险时使用现场机器人急停。菜单没有增加新的自动运动确认流程，原安全检查与 Enter 确认继续生效。

## 5. 丢边后的恢复

本次主配置使用 **2 mm 半径、0.5 mm/s 恢复速度、最多一次 360° 圆弧**，实际以生效配置为准。搜索速度、正常贴边控制和原接触确认条件保持原样。

恢复过程中重新满足接触条件时，先停车并确认停稳，再确认接触力、持续时间和方向，成功后继续跟踪。恢复不再因原 8 秒、4 mm 路径或位移预算提前结束。

程序结合实际 TCP 的连续角度记录及原位置跟踪容差判断圆弧完成，不能仅凭参考角度或终点与起点重合判定完成。实际完成整圈仍未建立有效接触时，停车并保存原因：

```text
RECOVERY_FULL_CIRCLE_NO_CONTACT
```

实际 TCP 明显停滞或跟踪参考点异常时，按运动执行异常停车并记录实际位置、参考位置、跟踪误差和角度。工作区域、速度与加速度、原力和力矩保护、传感器及 RTDE 异常处理、人工停止保持生效。

## 6. 日志和 HTML 保存位置

终端的 `Continuous run:` 给出本次完整目录。默认保存位置：

```text
ur7e_px6d_contour_clean/data/real/continuous/run_日期_时间/
ur7e_px6d_contour_clean/data/simulation/continuous/run_日期_时间/
```

| 查看内容 | 文件 |
|---|---|
| HTML 回放 | `实验回放.html` |
| 实际 TCP、力、速度、状态与恢复数据 | `samples.csv`、`full_log.csv` |
| 实际下发的 RTDE 指令 | `tcp_commands.csv` |
| 首次接触、恢复成功或失败等事件 | `policy_waypoints.csv` |
| 本次参数与贴边速度选择 | `config_snapshot.yaml`、`tracking_speed_selection.json` |
| 停止原因及实际停稳结果 | `termination.json`、`summary.json` |
| 目标轮廓副本（若有效） | `target_geometry_calibration.yaml` |

恢复数据包含起点、参考位置、实际 TCP 位置、参考及实际累计角度、实际速度、Fxy 和参考点跟踪误差。重新接触时的角度可结合 `REACQUIRED` 事件时间和对应样本查看。

用浏览器打开 `实验回放.html`。有有效目标轮廓时，“显示真实目标轮廓”默认开启，取消勾选隐藏叠加层。原播放、暂停、速度滑块、事件、局部缩放、力和速度曲线继续使用。

TCP 和恢复轨迹使用记录的真实运动数据，Base XY 等比例显示；不会用规划圆弧替代实际运动，也不吸附轨迹、不计算轨迹误差或探针半径补偿。目标文件在设备和日志关闭后用于回放，并保存本次副本。

## 7. 离线模拟与旧接口

菜单 `7` 使用独立合成场景，不读取现场 P0 或真实目标轮廓。模拟过程中也可能触发原保护而停车，可在日志中查看原因。

原有 `--execute`、`--p0`、`--dry-run`、`--check-calibration`、`--calibrate-target` 等命令行接口继续兼容；日常操作统一从上述菜单进入。`--duration` 仍只影响离线运行。

本次验证使用离线测试和模拟硬件。真机仍需验证 360° 恢复的实际跟随、执行异常判定、重新接触制动及现场工具/夹具空间；软件边界检查不包含未知夹具的碰撞模型。
